[ A. 현재 이미 적용된 사운드 — 제외 대상 (참고용) ]
==================================================================
AudioManager.cs 에서 실제로 로드/재생되는 8종만 "적용됨"으로 간주.

  - 검 공격음 (콤보 1·2타 / 3타)        Sound/Attack/SwordAttack_1·2
  - 창 공격음                            Sound/Spear/Slash_Attack_Light_2
  - 활 차징(당기기)음                    Sound/Bow/Slingshot_Stretch
  - 활 발사음                            Sound/Bow/Slash_Attack_Light_3
  - 피격음(공격이 적중)                  Sound/Hit/Hit_1
  - 대시음                               Sound/Dash/Dalsh_1
  - 저스트닷지 발동(슬로우다운)음        Sound/JustDodge/JustDodge_Slowdown
  - 발걸음(풀밭, a~f 순환)               Sound/Walk2/Footstep_Grass_a~f

[ 참고 ] 아래 에셋 팩은 프로젝트에 임포트만 되어 있고 코드에 전혀 연결되지 않음(미적용).
         신규 제작/구매 전 재활용 가능한지 우선 검토 권장.
  - Minifantasy_Dungeon_SFX (상자/문/궤짝/인간·오크 전투·점프·발소리 등)
  - RPG_Essentials_Free (Battle / UI Menu / Player Movement / Atk Magic SFX 등)

[ B. BGM / 배경음악 — 현재 전무, 최우선 필요 ]
==================================================================
AudioManager는 SFX 전용이며 음악 재생 기능·에셋이 전혀 없음. 전 구간 신규 필요.

  B-1. 타이틀/메인 메뉴 BGM
       - 느낌: 차분하면서 모험을 암시하는 오케스트라+민속 현악. 루프. 잔잔한 기대감.
  B-2. 필드 탐험 BGM (낮)
       - 느낌: 밝고 평화로운 어쿠스틱/플루트 중심. 가벼운 발걸음감, 넓은 공간감. 루프.
  B-3. 필드 BGM (밤)  (DayNightManager 연동)
       - 느낌: 낮 버전의 어둡고 미니멀한 변주. 저음 패드 + 희미한 불안감. 루프.
  B-4. 전투 BGM (일반 몹 교전)
       - 느낌: 빠른 타악기 + 긴장감 있는 현악. 위협 감지 시 페이드인. 루프.
  B-5. 보스전 BGM (골렘)
       - 느낌: 묵직한 저음 타악·합창·금관. 거대함과 압박. 페이즈 고조 변주 가능. 루프.
  B-6. 보스 등장 인트로 스팅어
       - 느낌: 5~8초. 정적 후 쾅 하는 충격 + 합창. 보스전 진입 연출용 (논루프).
  B-7. 안전지대 / 모닥불 휴식 BGM
       - 느낌: 따뜻한 어쿠스틱 기타·하프. 안도감, 회복의 분위기. 루프.
  B-8. 승리 / 보스 처치 팡파르
       - 느낌: 3~5초. 상승하는 금관·종소리. 성취감. 논루프.
  B-9. 사망 / 게임오버 BGM  (DeathScreenUI / DeathCutscene)
       - 느낌: 느리고 적막한 피아노/현. 상실감. 짧은 루프 또는 원샷.

[ C. 플레이어 전투 — 차지 스킬 / 무기 확장 ]
==================================================================
검·창·활·완드 각 3단계 차지 스킬(ChargeSkill) 존재하나 전용 SFX 없음.

  C-1. 검 차지스킬 1/2/3 (SwordChargeSkill1~3)
       - 1: 짧고 날카로운 강베기 "촤악". 금속 마찰 + 바람 가르기.
       - 2: 회전 베기. 묵직한 "후웅~촤" 연속 풍절음.
       - 3: 대형 충격파/내려치기. "쿠웅" 저음 + 금속 잔향, 화면을 채우는 임팩트.
  C-2. 창 차지스킬 1/2/3 (SpearChargeSkill1~3)
       - 1: 빠른 찌르기 "슉". 날카롭고 짧음.
       - 2: 관통 돌진. 바람 찢는 "쉬익~" + 적중 둔탁음.
       - 3: 광역 휩쓸기/마나창. "차아앙" 길고 웅장한 마력 잔향.
  C-3. 활 차지스킬 1/2/3 (BowChargeSkill1~3, 관통/조준사격 등)
       - 1: 강화 발사 "팅—슉". 시위 튕김 + 화살 풍절.
       - 2: 다중/연사. 빠른 "팅팅팅" 연속음.
       - 3: 차오른 한 발(관통). 길게 당기는 긴장음 후 "퉁!" 폭발적 발사 + 잔향.
  C-4. 완드 기본 마법탄 (MagicProjectile / WandBehaviour) — 속성별 3종
       - 불: "화륵-슉" 불꽃이 타오르며 날아가는 소리.
       - 얼음: "차르릉-슝" 서리·유리 결정 질감.
       - 땅: "두둑-퉁" 돌·흙 뭉치가 둔하게 날아가는 소리.
  C-5. 완드 차지스킬 1/2/3 (WandChargeSkill1~3)
       - 1: 단발 강화 마법 "파앗" 마력 방출.
       - 2: 광역 폭발/장판. "쿠과광" 깊은 마법 폭발 + 잔향.
       - 3: 궁극기급 대마법. 차징 고조음 → 거대한 "콰아앙" 해방감.
  C-6. 차징 충전 루프음 (ChargeSystem / ChargeVFXController)
       - 느낌: 에너지가 모이는 "우우웅~" 상승 루프. 단계 오를수록 음정 상승.
  C-7. 차징 풀충전 신호음 (Ready)
       - 느낌: "팅!" 또는 "차앙" 맑은 신호음. 발사 가능 알림.
  C-8. 무기 빗나감/헛휘두름 (whoosh / miss)
       - 느낌: 적 미적중 시 "후웅" 바람 가르는 풍절음. 무기별 톤 차이.
  C-9. 베쉬 스킬 (BashSkill)
       - 느낌: 방패/몸통 강타 "퉁!" 둔탁한 충격 + 살짝의 금속 울림.

[ D. 원소 시스템 (불 / 얼음 / 땅) ]
==================================================================
ElementType(Earth/Fire/Ice) + ElementalWeaponSystem + Debuff 존재하나 SFX 없음.

  D-1. 원소 전환 (우클릭, Earth→Fire→Ice 순환)
       - 느낌: 짧은 "촤락" 전환음. 속성별 미세 톤(불-탁탁, 얼음-챙, 땅-드르륵).
  D-2. 불 속성 부착/적중 (FireDebuff)
       - 느낌: "화르륵" 점화. 타격 시 불꽃 터지는 질감.
  D-3. 화상 지속 데미지 틱 (FireDebuff tick)
       - 느낌: 일정 간격 "치익~치익" 작게 타들어가는 루프성 짧은 음.
  D-4. 얼음 속성 부착/적중 (IceDebuff)
       - 느낌: "차르릉" 서리 맺힘 + 유리 깨지는 듯한 차가운 질감.
  D-5. 빙결/둔화 발동 (EnemySlowEffect / 동결)
       - 느낌: "쩌적-" 얼어붙는 크래킹음 + 둔탁하게 느려지는 저음.
  D-6. 땅 속성 부착/적중 (EarthDebuff)
       - 느낌: "두둑-쿵" 돌·바위 부딪는 묵직한 둔음, 약간의 흙먼지.
  D-7. 원소 게이지 충전/만충 (ElementalGaugeUI)
       - 느낌: 충전 시 미세 상승음, 만충 시 "차앙" 속성색 어울리는 신호음.
