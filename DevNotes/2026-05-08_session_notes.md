## ✅ 완료된 작업

### 1. 텔레키네틱 무기 비파괴적 트랜스폼 시스템 전면 리팩토링
- **문제**: 기존 상대적 Undo/Redo 방식(역 쿼터니언, 역 곱셈)은 쿼터니언의 비가환성으로 인해 매 프레임 오차가 누적되어 각도와 크기가 점점 틀어지는 근본적 결함이 있었음
- **해결**: **절대값 기반 Save/Restore 시스템** 도입
  - 위치/회전: 매 프레임 기본 상태를 절대값으로 저장 → 다음 프레임에서 정확히 복원 → 역연산 없음 → 오차 0
  - 스케일: `SwordBehaviour`가 `Update()`에서 flipY를 직접 설정하므로 save/restore하면 덮어써지는 문제 발견 → `_restBaseScale` + 현재 Y부호(flipSign) + punch로 매 프레임 절대 계산
- **파일**: `FloatingWeaponMotion.cs` (핵심 변경)

### 2. 무기 가시성 및 페이드 시스템
- 공격 종료 후 무기가 **애니메이션 종료 지점에서 그대로 투명해지며 소멸** (위치/각도 복귀 없음)
- 공격 시작 시 무기가 **애니메이션 시작 지점에서 페이드 인**
- 완전히 투명해지면 `SetActive(false)`로 비활성화하여 잔상 제거
- 재공격 시 `PlayerWeaponController`에서 `SetActive(true)` 호출하여 자동 활성화
- `OnEnable`에서 모든 모션 변수 초기화

### 3. 오르빗 애니메이션 정밀화
- `_equipDropOffset` (장착 시 위에서 떨어지는 효과)이 공격 중에도 Y값을 더하고 있어 오르빗이 위쪽으로 치우치던 버그 수정
- 공격 시 `_equipDropOffset = 0f`로 강제 초기화하여 플레이어 중심 대칭 오르빗 보장

### 4. 잔상(Ghost Trail) 로컬 좌표 전환
- 이동 중 공격 시 잔상이 플레이어 이동 방향으로 길게 늘어지는 문제 해결
- 월드 좌표 → 로컬 좌표 기반 거리 계산으로 전환
- 생성 시에만 월드 좌표로 변환하여 잔상이 제자리에 고정

### 5. 파티클 및 VFX 트리거 복원
- 코드 리팩토링 과정에서 누락된 `triggerStartParticle`, `triggerEndParticle` 변수 복원
- 중복 `OnEnable` 메서드 통합
